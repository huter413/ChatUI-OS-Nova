# ChatUI OS — Nova

Custom ROM project for the POCO X4 Pro 5G (veux).

Product: ChatUI OS
Device branding: ChatUI Nova
Architecture: ARM64 / arm64-v8a
Target source: LineageOS 23.2 device stack

This repository contains the reproducible source/build configuration for the complete ROM target. It is not considered a finished ROM merely because source files exist: the final state is reached only after CI produces and verifies the ROM artifacts.

See ROM_SPEC.md for the complete feature specification and RELEASE_CHECKLIST.md for the final-release gate.
