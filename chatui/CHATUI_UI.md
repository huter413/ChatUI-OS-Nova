# ChatUI Nova interface

- ChatUI OS / ChatUI Nova branding in SystemUI and Settings.
- Dark default theme and wallpaper resource.
- Android permissions, app management, notifications, display, sound, battery and security settings remain available.
- AOSP/Lineage keyboard stack is retained and configurable from Settings.
- Browser intents are supported; proprietary Chrome/GMS binaries are not redistributed in this public repository.
